# Code-Piece
SafeStreet is a community-driven street hazard reporting platform that helps people report potholes, open manholes, damaged footpaths, waterlogging, and other public safety issues. It features hazard reporting, location support, a safety map, repair tracking, and a city dashboard to promote safer streets and stronger communities.
# 🚧 SafeStreet — Street-Level Hazard Tracker

*Building safer streets through community reporting and better repair tracking.*

## 🌟 Features
•⁠  ⁠*Report Road Hazards:* Report potholes, open manholes, damaged footpaths, waterlogging, dangling wires, and garbage piles.
•⁠  ⁠*Location Support:* Optionally use your location when submitting a report.
•⁠  ⁠*Voice Input:* Describe hazards using supported browser speech recognition.
•⁠  ⁠*Photo Details:* Include photo information with a report.
•⁠  ⁠*Safety Map:* View sample hazard locations.
•⁠  ⁠*City Dashboard:* Explore reported issues and repair priorities.
•⁠  ⁠*Community Missions:* Participate in civic activities and earn demo points.
•⁠  ⁠*Funding & Rewards:* Explore community funding and reward concepts.
•⁠  ⁠*Responsive Interface:* Designed for desktop and mobile screens.

## 🚀 How to Run
1.⁠ ⁠Download the project files.
2.⁠ ⁠Open ⁠ safestreet_prototype.html ⁠ in your browser.
3.⁠ ⁠Explore the dashboard and try submitting a sample report.

You can also run a local server:
⁠ bash
python3 -m http.server 8000
 ⁠
Open ⁠ http://localhost:8000 ⁠ in your browser and select the HTML file.

## ⚠️ Note
SafeStreet is currently a prototype. Map locations, dashboard information, and reward amounts are sample data. Reports are saved locally in the browser and are not sent to government or municipal authorities. No real payments or rewards are processed.
